# Half-Life---Week-4-Displays
My project for week 4 of Half Life, designing a display. This is both a clock, and an environmental sensor. The PCB has a 4-digit 7-segment display, a real time clock module (ds3231s), a temperature/humidity sensor(dht11), a rotary encoder for navigation between different menus (ec11), and a connector for a strip of RGB LEDs (NeoPixels). The wiring for this PCB is horrible because I just started connecting dots until they couldn't, switched to back copper to do more, then used vias when I couldn't connect anymore (vias are a goated wiring function). The PCB also has 2 LEDs to indicate whether the time is AM or PM.
